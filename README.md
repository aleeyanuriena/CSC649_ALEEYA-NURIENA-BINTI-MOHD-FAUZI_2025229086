# Proposed Enhancement of Assignment Tracking and Attendance Monitoring in UiTM uFuture Using a Rule-Based Expert System

## Project Overview

This project proposes improvements to assignment tracking and attendance monitoring in UiTM uFuture using a Rule-Based Expert System. The proposed system uses predefined IF–THEN rules to classify assignment priorities based on deadlines and submission statuses.

The project also focuses on improving attendance information visibility and navigation. The proposed enhancements aim to help students identify urgent assignments and manage their academic activities more effectively.

## Problem Statement

Students may face difficulties identifying urgent assignments and monitoring attendance information across different courses in UiTM uFuture. Assignment deadlines and submission statuses may require students to check individual courses, making it difficult to prioritize tasks efficiently.

The proposed enhancement aims to provide a centralized Academic Dashboard with rule-based assignment priority classifications and attendance reminders.

## Proposed Enhancements

- **Academic Dashboard:** Displays pending assignments, deadlines, rule-based priority labels, and attendance reminders.
- **My Courses:** Displays course cards with pending tasks and upcoming deadlines.
- **Assignment:** Displays assignment details, submission statuses, priority classifications, and filtering options.
- **Attendance:** Displays attendance summaries, attendance statuses, and reminders for unmarked sessions.

## Rule-Based Assignment Priority Classification

The proposed Rule-Based Expert System uses predefined IF–THEN rules to classify assignments:

| Condition | Priority Classification |
|---|---|
| Assignment is submitted | Completed |
| Assignment is pending and deadline has passed | Overdue |
| Assignment is pending and due within 0–2 days | High |
| Assignment is pending and due within 3–5 days | Medium |
| Assignment is pending and has more than 5 days remaining | Low |

These classifications are proposed to appear on the Academic Dashboard to help students identify urgent assignments.

## Specialized Technology

The specialized technology selected for this project is a **Rule-Based Expert System**.

The proposed system uses a knowledge base, inference engine, working memory, and user interface to classify assignment priorities using predefined IF–THEN rules.

The project also considers a Decision Table to organize classification rules and Forward Chaining as the proposed reasoning method.

**Tools:**

## Project Status

This project is an academic proposal focusing on system requirements, rule-based priority classification, and proposed interface enhancements.

The project includes documentation and system diagrams. An interactive Figma prototype is planned to demonstrate the proposed features using sample data.

No backend implementation, live UiTM uFuture integration, or fully functional system development is included.
