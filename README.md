# UI/UX Enhancement of UiTM uFuture

## Project Overview
This project proposes user experience (UX) improvements to UiTM uFuture, focusing on assignment deadline tracking and attendance management. The proposed enhancements aim to improve information visibility, navigation, and usability for students.

## Problem Statement
Students may experience difficulties tracking assignment deadlines and attendance information across different courses. The proposed UX enhancements aim to provide a more organized and user-friendly interface.

## Proposed Enhancements
- **Academic Dashboard:** Centralized deadlines, pending assignments, priority labels, and attendance reminders.
- **My Courses:** Course cards displaying pending tasks and upcoming deadlines.
- **Assignment:** Assignment deadlines, submission status, and filtering options.
- **Attendance:** Attendance summaries, status information, and access to existing attendance marking functions.
