
## 3.1 Functional Requirements (B1)

The functional requirements describe the main features of the proposed UiTM uFuture enhancement, including assignment priority classification using a Rule-Based Expert System and attendance monitoring.

| ID | Functional Requirement |
|---|---|
| FR1 | The system shall display an Academic Dashboard once a student logs in. |
| FR2 | The system shall show pending assignments and deadlines. |
| FR3 | The system shall classify assignments using IF–THEN rules based on deadlines and submission statuses. |
| FR4 | The system shall show priority labels (High, Medium, Low, Completed, Overdue). |
| FR5 | The system shall display reminders for unmarked attendance. |
| FR6 | The system shall show course cards with pending tasks and deadlines. |
| FR7 | The system shall allow course searching and sorting. |
| FR8 | The system shall show assignment details and submission status. |
| FR9 | The system shall allow assignment searching and filtering. |
| FR10 | The system shall show attendance summaries and navigation links. |
