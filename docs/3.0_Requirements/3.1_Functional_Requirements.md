# 3.0 REQUIREMENTS

  # 3.1 Functional Requirements

  | ID | Functional Requirement |
  |---|---|
  | FR 1 | The system shall display a centralized Academic Dashboard after student login. |
  | FR 2 | The system shall display pending assignments and upcoming deadlines on the Academic Dashboard. |
  | FR 3 | The system shall highlight urgent assignments using clear priority labels. |
  | FR 4 | The system shall display an attendance reminder when a student's attendance is not marked. |
  | FR 5 | The system shall display course cards with pending assignment counts and nearest deadlines on the My Courses page. |
  | FR 6 | The system shall allow students to search and sort courses on the My Courses page. |
  | FR 7 | The system shall display assignment deadlines, priority labels, and submission status on the Assignment page. |
  | FR 8 | The system shall allow students to search and filter assignments by course or submission status. |
  | FR 9 | The system shall display attendance summaries and attendance status on the Attendance page. |
  | FR 10 | The system shall provide navigation to existing uFuture pages for assignment details and attendance marking. |
