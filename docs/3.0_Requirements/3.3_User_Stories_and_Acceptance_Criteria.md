
## 3.3 User Stories and Acceptance Criteria (B3)

The following user stories describe students' needs and the acceptance criteria for evaluating the proposed prototype.

### User Story 1: Academic Dashboard (FR2, FR3, FR4)

**User Story:**

As a student, I want to view assignment deadlines and automatically classified priorities to manage urgent tasks efficiently.

**Acceptance Criteria:**

1. Displays pending assignments and deadlines using sample data.
2. Classifies assignments using IF–THEN rules and displays the resulting priority labels.

### User Story 2: Assignment Management (FR8, FR9)

**User Story:**

As a student, I want to view and filter assignments to track deadlines and submission statuses.

**Acceptance Criteria:**

1. Displays assignment deadlines, priority labels, and submission statuses.
2. Allows filtering by course or submission status in the prototype.

### User Story 3: Attendance Tracking (FR5, FR10)

**User Story:**

As a student, I want to check attendance statuses and reminders to avoid missing attendance marking.

**Acceptance Criteria:**

1. Displays attendance summaries and statuses using sample data.
2. Shows a reminder when an attendance session is marked "Not Marked".
