# 3.3 User Stories and Acceptance Criteria (B3)

The user stories describe students' needs, while the acceptance criteria explain how each feature can be tested in the proposed prototype.

## User Story 1: Academic Dashboard

**Related Requirements:** FR2, FR3

As a student, I want to view my pending assignments and upcoming deadlines in one dashboard, so that I can manage my academic tasks more easily.

**Acceptance Criteria:**

1. The Academic Dashboard displays pending assignments and upcoming deadlines from multiple courses using sample data.
2. Urgent assignments are clearly highlighted with priority labels.

## User Story 2: Assignment Management

**Related Requirements:** FR7, FR8

As a student, I want to view and filter my assignments, so that I can identify important tasks and their submission status.

**Acceptance Criteria:**

1. The Assignment page displays assignment deadlines, priority labels, and submission statuses.
2. Students can use the prototype's filter controls to view assignments by course or submission status.

## User Story 3: Attendance Tracking

**Related Requirements:** FR4, FR9

As a student, I want to check my attendance status and reminders, so that I can avoid forgetting to mark my attendance.

**Acceptance Criteria:**

1. The Attendance page displays attendance summaries and check-in statuses using sample data.
2. An attendance reminder is shown when a sample attendance session has a Not Marked status.
