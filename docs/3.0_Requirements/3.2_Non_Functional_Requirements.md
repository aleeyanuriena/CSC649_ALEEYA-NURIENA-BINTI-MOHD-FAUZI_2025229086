# 3.2 Non-Functional Requirements (B2)

The non-functional requirements describe the quality standards of the proposed uFuture UI/UX prototype.

| ID | Category | Non-Functional Requirement |
|---|---|---|
| NFR1 | Usability | The proposed interface shall allow students to find an upcoming assignment deadline within three clicks from the Academic Dashboard. |
| NFR2 | Usability | The proposed interface shall allow students to access the Attendance page within two clicks from the Academic Dashboard. |
| NFR3 | Performance | The proposed prototype shall allow students to complete the navigation from the Academic Dashboard to any of the three redesigned pages within three clicks. |
| NFR5 | Reliability | The interactive prototype shall allow students to complete all three main navigation paths without broken links. |
| NFR6 | Consistency | The proposed interface shall use the same navigation layout across all four proposed pages. |
