# 1.2 Chosen Specialized Technology

The chosen specialized technology for the project is Rule-Based Expert System (RBES). This type of artificial intelligence (AI) makes decisions by following a set of predefined IF–THEN rules and produces consistent results without the need for training data.

The project utilizes a Rule-Based Expert System to classify assignment priorities for UiTM uFuture enhancement. Pending assignments that are due in 2 days are classified as High Priority, while those with more than 5 days remaining are classified as Low Priority. Submitted assignments are marked as Completed. This feature is intended to help students identify urgent tasks and complete assignments on time.

In addition to assignment tracking, the project focuses on improving attendance monitoring. This is done by displaying attendance summaries and reminders for unmarked sessions. The project will use Figma to design an interactive prototype of the Academic Dashboard, My Courses, Assignment, and Attendance pages. It will demonstrate the proposed features of the project using sample data without developing a system or modifying the existing UiTM uFuture platform.
