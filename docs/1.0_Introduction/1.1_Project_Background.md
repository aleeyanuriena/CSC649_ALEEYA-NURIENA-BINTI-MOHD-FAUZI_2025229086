# 1.1	Project Background

The uFuture is an online learning platform used by Universiti Teknologi MARA (UiTM) students to access course materials, assignments, assessments and class attendance. In a semester, students are required to manage academic activities in several courses. However, important information such as assignment deadlines and attendance is available on different course pages. Thus, students need to navigate to different sections to access the information. 

Therefore, this project proposes UI/UX enhancement on the existing UiTM uFuture platform. The proposed enhancement aims to provide a centralized Academic Dashboard and enhance three existing pages such as My Courses, Assignment and Attendance. This enhancement will offer clear information, easier navigation and more organized interface to help students effectively manage their academic activities.
