# 4.2 UX Frameworks, Methods and Tools
	
Several frameworks, methods, and tools can be used in UX design to improve the usability of digital systems. For the proposed UiTM uFuture enhancement, User-Centred Design (UCD), wireframing, usability testing, and Figma are relevant approaches.

Firstly, User-Centred Design (UCD) focuses on understanding users' needs throughout the design process. In this project, UCD would help identify the difficulties students face when checking assignment deadlines and attendance information. By understanding these problems, the proposed improvements can better support students in managing their academic activities.

Next, wireframing is a method used to plan the basic layout and structure of an interface before creating a detailed design. For UiTM uFuture, wireframes could be used to organize the Academic Dashboard, assignment deadlines, attendance reminders, and navigation menus more clearly.

Furthermore, usability testing is a method used to evaluate how easily users can complete specific tasks using an interface. For example, students could be asked to find their nearest assignment deadline or check their attendance status using the proposed design. Their feedback would help identify confusing elements and areas that need improvement.

Finally, Figma is a UI/UX design and prototyping tool used to create interface layouts and interactive prototypes. It could be used in a future design phase to demonstrate how students would navigate between the Academic Dashboard, My Courses, Assignment, and Attendance pages.
