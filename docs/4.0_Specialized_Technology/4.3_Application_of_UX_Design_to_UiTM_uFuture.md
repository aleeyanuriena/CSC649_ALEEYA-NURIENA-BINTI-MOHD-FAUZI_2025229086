# 4.3 Application of UX Design to UiTM uFuture
	
UX Design is suitable for the proposed UiTM uFuture enhancement because it focuses on improving how students access and manage academic information. Currently, students may need to navigate through different course pages to check assignment deadlines and attendance information. By applying UX design principles, the proposed enhancement aims to make these activities easier and more organized.

Firstly, a centralized Academic Dashboard is proposed to display upcoming assignment deadlines and attendance reminders in one place. This would help students identify important academic tasks without checking each course separately. In addition, clear priority indicators could help students recognize assignments that require immediate attention.

Furthermore, improvements to the My Courses, Assignment, and Attendance pages could provide clearer information and more consistent navigation. For example, the Assignment page could display submission statuses and upcoming deadlines, while the Attendance page could show attendance summaries and check-in reminders. These improvements could reduce unnecessary navigation and help students manage their academic responsibilities more efficiently.

However, there are several limitations to consider. Firstly, the proposed design may not meet every student's preferences because students have different needs and ways of using the platform. Therefore, user feedback and usability testing would be important to identify areas that require improvement. Secondly, the proposed enhancement is limited to interface design and prototyping. Features such as automatic attendance updates and real-time assignment notifications would require backend integration, which is outside the scope of this project.

Alternatively, the existing uFuture interface could be improved by providing students with a user guide or tutorial explaining how to navigate the current pages. This approach would be easier to introduce because it would not require changes to the interface. However, students would still need to access different course pages to check their academic information. In comparison, the proposed UX enhancement would address the navigation problem more directly by organizing important information into a centralized dashboard.

Therefore, UX Design is the preferred approach because it focuses on improving the actual experience of students rather than only teaching them how to use the existing interface. Although the proposed enhancement would require further evaluation before implementation, it offers a practical direction for improving assignment deadline tracking and attendance management in UiTM uFuture.
