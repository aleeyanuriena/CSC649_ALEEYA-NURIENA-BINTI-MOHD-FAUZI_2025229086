# 4.2 Frameworks, Models, Methods and Tools (C2)

The proposed architecture for the project is a Rule-Based Expert System (RBES) that consists of a Knowledge Base, Inference Engine, Working Memory, and User Interface. The RBES architecture processes assignment information to classify priorities based on a set of rules.
Next, the Decision Table is selected to represent assignment conditions and results. This will be used to show the submission status of an assignment as well as the number of days left to complete the assignment. The resulting classification of the assignment as High, Medium, Low, Completed, or Overdue will be clearly stated in the Decision Table.
Forward Chaining is the proposed method to determine assignment priorities. It starts with available information, such as assignment deadlines and submission statuses, and checks the facts against predefined IF–THEN rules to produce the appropriate priority classification.
The tools chosen for this project are Figma and draw.io. Figma will be used to create the interactive prototype of the Academic Dashboard, My Courses, Assignment and Attendance pages. draw.io will be used to create the system flowchart and the Rule-Based Expert System architecture diagram. These tools will be used to represent the solution proposed for this project without creating a fully functional system.
