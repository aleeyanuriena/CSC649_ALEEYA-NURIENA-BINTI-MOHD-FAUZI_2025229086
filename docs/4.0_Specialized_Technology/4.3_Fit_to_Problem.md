
# 4.3 Fit to the Problem (C3)

## 4.3.1 How Technology Addresses the Problem

The proposed Rule-Based Expert System addresses the difficulty students face in identifying urgent assignments across different courses in UiTM uFuture. It uses predefined IF–THEN rules based on assignment deadlines and submission statuses to classify assignments as High, Medium, Low, Completed, or Overdue.

The classifications are proposed to appear on the Academic Dashboard. This helps students identify urgent tasks without checking each course individually. The Figma prototype will show the priority indicators using sample data. This helps students understand how the proposed system could improve assignment tracking and time management.

## 4.3.2 Benefits of Using Rule-Based Expert System

The proposed uFuture enhancement can benefit from the Rule-Based Expert System. Firstly, it offers consistent assignment prioritization by applying the same IF–THEN rules to deadlines and submission statuses. Secondly, it provides transparent and explainable decisions. This allows students to understand why an assignment receives a certain priority label.

Besides, it does not require large training datasets. This makes the system simpler to design and maintain compared to machine learning for simple classification tasks. This may help students identify urgent assignments and manage their academic workload effectively.

## 4.3.3 Limitations and Risks of Rule-Based Expert System

The Rule-Based Expert System has several limitations. Firstly, it depends on predefined IF–THEN rules and cannot automatically adapt to new situations without manual updates. Secondly, inaccurate deadlines or submission statuses may lead to incorrect priority classifications.

In addition, the system only considers predefined conditions. This means that assignment difficulty or workload may not be taken into account. Therefore, the proposed rules should be reviewed regularly, and assignment information should be verified before classification.

## 4.3.4 Selected Technology and Justification

The Rule-Based Expert System is chosen for this project because it is simple, easy to understand, and suitable for assignment priority classification. The proposed system can determine assignment priorities based on deadlines and submission statuses using predefined IF–THEN rules. This allows students to understand why an assignment is classified as High, Medium, Low, Completed, or Overdue.

Compared to Machine Learning, this technology is more suitable for the project because it does not require training data and is easier to design. Figma will be used to demonstrate the proposed classification results through an interactive prototype without developing a fully functional system.
