# 4.1 Fundamental Concepts (C1)

		# 4.1.1 What is Rule-Based Expert System?

Rule-Based Expert System is a type of artificial intelligence (AI) that uses predefined IF-THEN rules to make decisions based on certain conditions. It is different from machine learning as it does not learn from training data. It uses the rules defined based on human knowledge or expertise.
The system consists of a knowledge base that contains the rules. There is also an inference engine that evaluates the information with the rules to make decisions.
For the proposed UiTM uFuture enhancement, this technology is used to classify the assignment priority based on the deadline and submission status. For example, IF the assignment is pending and due within 2 days, THEN it is classified as High Priority. This helps students to identify the urgent tasks more effectively and manage their academic activities.

    # 4.1.2 Key Concepts of Rule-Based Expert System
A Rule-Based Expert System consists of four main components: the knowledge base, inference engine, working memory, and user interface.
1. Knowledge Base
The knowledge base of a Rule-Based Expert System contains the predefined IF-THEN rules used for decision making. For example, IF an assignment is pending and due within two days, THEN its priority is High.


2. Inference Engine
The inference engine compares the assignment information with the rules in the knowledge base and classifies the assignment into the corresponding priority category.
3. Working Memory
Working Memory stores information about current assignments (e.g. deadlines, submitted, days left) for evaluation by the rules in the knowledge base.
4. User Interface
The user interface displays the results of the classification on the proposed Academic Dashboard, as High, Medium, Low, Completed, or Overdue.
Overall, these components work together to systematically classify assignments in order to help students to prioritize their work in an effective manner.

  # 4.1.3 How Rule-Based Expert System Works
Rule-Based Expert System works by evaluating the input information with the predefined IF-THEN rules. For the proposed uFuture enhancement, the assignment deadline and submission status are stored as facts in the working memory. The inference engine then checks the facts with the rules in the knowledge base to determine the classification.
For example, the submitted assignment is classified as Completed. The pending assignment with passed deadline is classified as Overdue. The pending assignment with due within 2 days is classified as High Priority. The pending assignment with due within 3 to 5 days is classified as Medium Priority. The pending assignment with remaining more than 5 days is classified as Low Priority. The classification result is displayed on the proposed Academic Dashboard. This helps students to identify the urgent assignment.
