
# 4.1 Fundamental Concepts (C1)

## 4.1.1 What is Rule-Based Expert System?

Rule-Based Expert System is a type of artificial intelligence (AI) that uses predefined IF–THEN rules to make decisions based on certain conditions. It is different from machine learning as it does not learn from training data. It uses rules defined based on human knowledge or expertise.

The system consists of a knowledge base that contains the rules. There is also an inference engine that evaluates the information against the rules to make decisions.

For the proposed UiTM uFuture enhancement, this technology is used to classify assignment priorities based on deadlines and submission statuses. For example, IF an assignment is pending and due within 2 days, THEN it is classified as High Priority. This helps students identify urgent tasks more effectively and manage their academic activities.

## 4.1.2 Key Concepts of Rule-Based Expert System

A Rule-Based Expert System consists of four main components: the knowledge base, inference engine, working memory, and user interface.

1. **Knowledge Base**

   The knowledge base of a Rule-Based Expert System contains predefined IF–THEN rules used for decision-making. For example, IF an assignment is pending and due within two days, THEN its priority is High.

2. **Inference Engine**

   The inference engine compares assignment information with the rules in the knowledge base and classifies the assignment into the corresponding priority category.

3. **Working Memory**

   Working memory stores information about current assignments (e.g., deadlines, submission statuses, and days remaining) for evaluation against the rules in the knowledge base.

4. **User Interface**

   The user interface displays the classification results on the proposed Academic Dashboard as High, Medium, Low, Completed, or Overdue.

Overall, these components work together to systematically classify assignments and help students prioritize their work effectively.

## 4.1.3 How Rule-Based Expert System Works

A Rule-Based Expert System works by evaluating input information against predefined IF–THEN rules. For the proposed uFuture enhancement, assignment deadlines and submission statuses are stored as facts in working memory. The inference engine then checks these facts against the rules in the knowledge base to determine the classification.

For example, a submitted assignment is classified as Completed. A pending assignment with a passed deadline is classified as Overdue. A pending assignment due within 2 days is classified as High Priority. A pending assignment due within 3 to 5 days is classified as Medium Priority. A pending assignment with more than 5 days remaining is classified as Low Priority.

The classification result is displayed on the proposed Academic Dashboard. This helps students identify urgent assignments.
